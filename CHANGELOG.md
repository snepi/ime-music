# Changelog

Все заметные изменения для пользователей публикуются здесь и дублируются в **GitHub Releases**.

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.2] — 2026-08-20

### Added
- Экспорт / импорт бэкапа библиотеки одним JSON: лайки, плейлисты, wishlist и настройки discovery
- Умные миксы по жанру из **локальной** библиотеки (чипы на Главной; радио продолжает подбирать треки того же жанра)

### Notes
- В бэкап не входят аудиофайлы — при импорте треки сопоставляются по названию и исполнителю
- IMe Waves по-прежнему играет демо-превью; жанровые миксы — только ваши файлы на диске

## [1.0.1] — 2026-08-20

### Added
- Автообновления: проверка новой версии на GitHub Releases
- Кнопка «Скачать и установить» в **Настройки → Инструменты**
- Прогресс скачивания установщика и автозапуск Setup

### Notes
- Обновление ставится через официальный NSIS Setup из Releases
- Portable-сборку по-прежнему можно скачать вручную со страницы релиза

## [1.0.0] — 2026-08-20

### Added
- Первый публичный релиз IMe Music для Windows
- Локальная библиотека, рекомендации, IMe Waves
- Система кастомизации (темы, обои, пресеты)
- Установщик Setup и Portable-сборка
