# Changelog

Все заметные изменения для пользователей публикуются здесь и дублируются в **GitHub Releases**.

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-08-20

### Added
- Медиакнопки и панель Windows (Media Session): play/pause, next/prev, название и обложка
- Метка «Есть у меня» для демо (Deezer + Apple Music / iTunes) и «Хочу послушать» — если трек уже в библиотеке, играет полный файл
- Умные подборки на Главной в виде карточек-альбомов (клик сразу играет): часто слушаю, новые, лайки, давно не звучало, рейтинг, 90-е и **подборки по жанрам** из вашей библиотеки
- Импорт плейлиста **по ссылке**: Яндекс.Музыка, YouTube Music, Spotify, Apple Music (CSV/M3U — запасной вариант)
- Текст песни: в «Изменить метаданные» можно вставить текст или загрузить `.lrc` / `.txt`; просмотр из нижней панели плеера
- Поиск пропавших файлов и привязка к новой папке (Настройки → Инструменты)
- Короткий онбординг при первом запуске (пустая библиотека)
- Умнее поиск по библиотеке: транслит RU↔латиница, префикс `format:`

### Changed
- Умные подборки убраны из бокового меню и стоят на Главной после «Недавно» / «Похоже»
- Поиск трека через yt-dlp выбирает лучшее совпадение по названию и исполнителю (меньше чужих каверов/ремиксов); при низкой уверенности просит прямую ссылку
- Виртуализация списка библиотеки включается раньше (с ~40 треков)

### Notes
- Для импорта YouTube Music / скачивания нужен yt-dlp (путь в Настройки → Инструменты)
- Плейлисты по ссылке должны быть открытыми; «Понравившаяся музыка» в YouTube Music часто недоступна без публичной ссылки

## [1.0.4] — 2026-08-20

### Changed
- Порядок блоков на Главной: поиск → демо → Слушать (Waves, микс дня, жанры) → недавно → похоже → избранные артисты
- Убран блок «Продолжить» (продолжение — из нижней панели плеера)

## [1.0.3] — 2026-08-20

### Changed
- Главная пересобрана: сначала «Продолжить» и библиотека, затем зона «Слушать» (микс дня / жанры / Waves), внизу «Открывать»
- Единый ритм отступов и панелей вместо хаотичной стопки блоков

## [1.0.2] — 2026-08-20

### Added
- Экспорт / импорт бэкапа библиотеки одним JSON: лайки, плейлисты, wishlist и настройки discovery
- Умные миксы по жанру из **локальной** библиотеки (чипы на Главной; радио продолжает подбирать треки того же жанра)

### Notes
- В бэкап не входят аудиофайлы — при импорте треки сопоставляются по названию и исполнителю
- IMe Waves по-прежнему играет демо-превью; жанровые миксы — только ваши файлы на диске
